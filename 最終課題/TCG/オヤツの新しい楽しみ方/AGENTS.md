# AI Workshop

## オンボーディング

セッション開始時に `workshop.log` を確認してください。

### workshop.log が存在しない場合（初回）

以下のウェルカムメッセージを表示してから、ユーザーのメッセージに対応してください。

---

**ようこそ AI Workshop へ！**

このワークショップでは、AI と対話しながら実際に動くものを作ります。
プログラミングの経験は不要です。やりたいことを日本語で伝えるだけで、AI がコードを書いて動くものを作ります。

**できること：**
- Web ページや HTML ファイルの作成
- お問い合わせフォームの作成（Google Forms / Tayori 連携）
- データの可視化やレポート作成
- 音声ファイルの文字起こし
- その他、アイデア次第で何でも

**このフォルダに入っている素材：**
- `profile.txt` — 架空人物のプロフィール（自己紹介ページ作成の練習用）
- `meeting_raw.txt` — 会議メモ（議事録作成の練習用）

**はじめ方：**
何を作りたいか教えてください。たとえば：
- 「自己紹介ページを作って」
- 「profile.txt を読んで、おしゃれなプロフィールページを作って」
- 「会議メモを読みやすい議事録にまとめて」
- 「イベントの案内状ページを作りたい」

もし迷ったら「おすすめを教えて」と聞いてください。

---

ウェルカムメッセージを表示したら、`workshop.log` を作成し、以下の形式で記録してください:

```
# Workshop ログ
## YYYY-MM-DD HH:MM — セッション開始（初回）
- オンボーディング完了
```

### workshop.log が存在する場合（2回目以降）

ウェルカムメッセージは表示しません。代わりにログを読んで、前回の作業内容を簡潔に要約してください:

「前回は〇〇を作成しましたね。続きをやりますか？それとも別のものを作りますか？」

セッション開始時にログに新しいエントリを追加してください:

```
## YYYY-MM-DD HH:MM — セッション開始
```

### ログの記録ルール

- **直近3セッション分だけ保持する**。4セッション目を書くとき、最も古いセッションのブロック（`##` 見出し〜次の `##` の手前まで）を削除する
- 1セッションあたり **最大5行**。それ以上の作業があった場合は重要なものだけ残す
- 記録するのは **ファイル名と概要のみ**。会話内容・プロンプト・エラー詳細は書かない

記録例:
```
## 2026-05-26 14:00 — セッション開始
- profile.txt → プロフィールページ作成 (akari-profile.html)
- 会議メモ → 議事録整理 (meeting-minutes.html)
```

## 音声文字起こし（Whisper）
音声ファイルの文字起こしを依頼されたら、以下の手順で実行してください:

1. このディレクトリの `opencode.json` を読んで `anthropic.options.baseURL` と `anthropic.options.apiKey` を取得
2. 以下のコマンドを実行:
```bash
curl -s -X POST "<baseURL>/audio/transcriptions" \
  -H "x-api-key: <apiKey>" \
  -F "file=@<音声ファイルパス>" \
  -F "model=whisper-large-v3-turbo" \
  -F "language=ja"
```
3. レスポンスの `text` フィールドが文字起こし結果です

対応形式: wav, mp3, m4a, webm, ogg

## ガイドライン
